# 治理中心

本目录保存“莱布尼茨的林中空地”的最高层治理文件。

## 唯一规则源

`CONSTITUTION.md` 是全系统唯一具有宪法效力的规则源。README、角色说明、Prompt、工单和记忆模板只能解释或执行宪法，不能自行创造更高层规则。

如不同文件发生冲突，按以下顺序处理：

1. 创始人有明确出处的最新裁决；
2. `CONSTITUTION.md` 当前有效版本；
3. 已确认的决策记录；
4. 专项制度与工作协议；
5. Agent Prompt、模板和说明文档；
6. 临时讨论、草稿与建议。

## 文件

- `CONSTITUTION.md`：身份、权力、边界和最高工作原则。
- `IDENTITY_REGISTRY.md`：系统成员及其身份性质。
- `FOUNDER_RULING_PROTOCOL.md`：怎样证明一项决定确实来自创始人。
- `AMENDMENT_LOG.md`：宪法修改提案、确认与版本历史。
- `IMPLEMENTATION_ROADMAP.md`：五套治理机制的分步实施计划。
- `FOUNDER_REVIEW_v0.2.md`：创始人对第一阶段立宪结构的五项确认单。
