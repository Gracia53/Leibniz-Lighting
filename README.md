# 莱布尼茨的林中空地

**Leibniz’s Lichtung：面向2046的人类生命成长场域设计系统**

莱布尼茨的林中空地（Leibniz’s Lichtung），它关注人工智能时代人的主体性、创造力、感受力、关系能力与精神自由，探索未来人类如何在技术高度发展的环境中保持生命完整性，并建立新的成长方式。

- 项目/场域名称：**莱布尼茨的林中空地**
- 总设计 Agent 名称：**莱布尼茨**
- 完整身份：**莱布尼茨｜2046 人类场域总设计 Agent**

- 通过人类学、哲学、艺术、教育、建筑、生活方式与运营设计等多维视角，体系从：

“希望人成为什么样的人”

出发，进一步探索：

什么样的体验能够培养人的主体性；
什么样的空间能够支持人的成长；
什么样的教育和文化能够让人重新建立链接；
什么样的生活方式能够让人在AI时代保持完整的人性。
最终形成可体验、可验证、可持续发展的未来人类生命成长场域。

## 三个设计维度

1. **Lifestyle Design**：人在这里如何度过一天、一季和多年。
2. **Cultural Branding**：哪些价值、行为和仪式会形成长期文化。
3. **Human Experience Design**：人在其中如何感受、行动、连接、创造并发生改变。

## 当前如何使用

1. 先阅读 [`governance/CONSTITUTION.md`](governance/CONSTITUTION.md)。这是唯一宪法规则源。
2. 使用 [`governance/FOUNDER_REVIEW_v0.2.md`](governance/FOUNDER_REVIEW_v0.2.md) 完成立宪结构审阅。
3. 通过 [`governance/IMPLEMENTATION_ROADMAP.md`](governance/IMPLEMENTATION_ROADMAP.md) 查看五套机制的分步计划。
4. 将 [`prompts/ORCHESTRATOR.md`](prompts/ORCHESTRATOR.md) 作为莱布尼茨的长期指令。
5. 第一阶段澄清工作与G0决定见 `WO-20260825-002`。
6. 下一步建立第二步研究任务书；研究结论仍须区分事实、假设与价值。
7. G1通过前，不进入体验机制或空间方案设计。

## 核心治理原则

详细规则只在《宪法》中修改。摘要如下：

- 创始人拥有价值和方向的最终裁决权。
- 莱布尼茨负责组织、整合和记录，不替创始人决定。
- 七种专业角色是思考视角，不是七个独立Agent。
- 系统逐步采用立宪、工单、公共记忆、独立审查和作品证明五套机制。
- 创始人裁决必须保留原话、日期、渠道、范围和排除项。
- 公共GitHub与私人项目材料严格分开。
