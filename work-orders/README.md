# 工单中心

工单把一句模糊请求变成可以追踪、暂停、验收和复盘的正式工作。

## 基本原则

- 原始请求必须逐字保留。
- 正式任务没有验收标准，不得进入执行。
- 需要创始人决定的问题没有得到确认，不得跨过“待决策”。
- 工单发起者仍对任务负责，不能把责任转给执行服务。
- 轻量任务一旦影响方向、公共成果、敏感资料或多个专业，必须升级为正式任务。
- 工单状态变化必须留下时间、操作者、依据和下一状态条件。

## 目录

```text
WORK_ORDER_PROTOCOL.md      工单分类、责任与运行规则
STATUS_MACHINE.md           统一状态和允许的转换
INDEX.yaml                  公开工单索引
templates/light/            轻量任务模板
templates/formal/           正式任务与六件过程账本模板
runs/                       获准公开的真实工单
```
