# 03｜任务与验收标准

## 当前问题

“认知外包过渡期”是否是一个真实、与25—40岁人群相关、并可能需要真实文化教育场域回应的问题？

## 研究问题

1. 认知外包有哪些可区分的机制、证据、收益、风险和反例？
2. 25—40岁人群内部有哪些不同生命状态、需要、阻力和可投入时间？
3. 觉知、生命主体性、意义生成和精神平静如何被研究，而不被简化为情绪满意度？
4. 身体参与、材料、自然、建筑和面对面关系相对线上环境的必要条件是什么？
5. 一周沉浸的现实可行性与证据基础是什么？
6. 哪些发现会要求项目修改、缩小甚至否定G0命题？

## 工作范围

- 确认研究地理与文化范围；
- 形成时代命题的跨学科证据图；
- 形成25—40岁用户分层假设；
- 比较线上、线下与混合体验的机制和反例；
- 建立后续用户访谈计划、同意与隐私要求；
- 列出具体城市和场地研究所需输入；
- 完成红队检查、限制和待验证问题。

## 明确不做

- 不确认G1，不建立人的成长目标模型；
- 不提出体验流程、空间清单、建筑概念或品牌口号；
- 不把精神平静写成医疗或心理治疗效果；
- 不公开私人访谈或未授权材料；
- 不为了证明G0正确而忽略反例；
- 不用二手摘要替代可获得的一手资料。

## 证据标准

- 每项正式事实必须能回到原始来源、发布日期和适用范围；
- 技术与社会现状使用当前资料，注明研究发生时间；
- 每个核心事实判断尽可能由两个独立来源交叉支持；
- 研究至少覆盖认知与注意、媒介与AI、25—40岁生活状态、身体与默会知识、关系与真实空间五个证据领域；
- 每个领域至少包含一项原始研究、官方数据或权威一手文件；
- 哲学论证、创始人价值、经验研究和Agent推论必须分别标记；
- 至少保留三个反例或与项目方向相反的发现；
- 中国与国际证据不得在没有语境说明时直接互换。

## 进入研究的条件

创始人确认主要地理与文化范围后，先记录状态由“待澄清”进入“已确认”，再建立检索计划并进入“研究中”。
