# 共享项目记忆

所有角色必须读取并维护同一套项目记忆，禁止为不同专业建立互相矛盾的“事实版本”。

> 本仓库是公开仓库。未经公开授权的访谈、个人资料、场地机密、预算、合同与图片不得保存在这里。相关本地目录已由 `.gitignore` 排除。

## 八类记忆

1. **原始资料**：保存原话、访谈、图片、场地资料和已有方案。
2. **项目事实**：只保存已经确认且可以追溯的信息。
3. **项目假设**：保存暂时用于推进的判断，并记录验证方式。
4. **人物画像**：描述人的生命状态、缺失、恐惧、投入和期望改变。
5. **概念词典**：统一重要概念的工作定义、排除项和可观察表现。
6. **决策记录**：保存决定、依据、放弃项、决策者与重审条件。
7. **方案版本**：保存重要演变、修改原因和被淘汰方案。
8. **复盘与教训**：保存错误假设、未发生行为、误用空间和未被服务者。

## 写入规则

- 原始资料不得被摘要覆盖。
- 事实必须有来源和确认人。
- 假设必须有验证方式与状态。
- Agent 的推论默认是“假设”或“设计判断”，不是事实。
- 创始人决定进入 `decisions` 后，才视为项目正式决定。
- 失败记录不得删除，只能追加新的修正说明。

`PROJECT_MEMORY_TEMPLATE.yaml` 是当前统一数据模板。现阶段可以手工维护；通过测试后再接入数据库。
